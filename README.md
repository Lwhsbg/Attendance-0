## Attendance 0

Demo: https://lwhsbg.itch.io/attendance-0

# What It Is

It is a short dark themed visual novel where you discover some strange phenomena in your school after staying a bit late to complete your assignments.

# Why I Made It

I needed to do a quick project before the deadline and this does not match with the long renpy games I usually make, but an Idea different fom my usual house based horror came up and I had a perfect opportunity to experiment this new theme.

# How I Made It

Tech stack:

- Renpy

# What I Struggled With & What I Learned

I did not really struggled making this project as it was a very simple one, but something new was thinking about a new theme so it felt like a completely different type of game than I would usually make, and I recently just realized you can make a readme on vscode itself, I always used to do it from github.
